About the session

Contemporary orthodontic diagnosis has transformed from analogue to digital 3D and 4D. Intraoral scans and digital models have replaced impressions and plaster models. CBCTs for complex cases have enabled us to diagnose more precisely. The aim of this demonstration-based lecture is to enable participants to use the various tools of the open-source software 3D Slicer and ITK-SNAP, with unrestricted free usage.

Learning objectives

At the end of the session, participants will be able to:

  • Perform digital model analysis using 3D Slicer.
  • Analyse the maxillomandibular and dental relationship using 3D cephalometrics.
  • Diagnose facial asymmetry in 3D.
  • Localise impacted and transposed teeth accurately in 3D and plan treatment.
  • Apply AI-based segmentation of DICOM data to create STL files with 3D Slicer, for 3D printing and CBCT superimpositions.
  • Carry out semi-automatic segmentation of facial structures with ITK-SNAP and 3D Slicer.
  • Measure airway volume by segmentation with ITK-SNAP.
  • Perform 3D facial scans with a mobile application and measure them in Blender.
  • Superimpose pre- and post-treatment CBCTs using the gold-standard voxel-based method.

Before you arrive — software setup

Please complete these steps on your own laptop before the session. The last step downloads several gigabytes of AI models, so do it on a good internet connection and leave time for it.

  1. Install 3D Slicer 5.12.3

    Download version 5.12.3 for your operating system from the official site and install it: download.slicer.org.

  2. Install the NNUNet extension

    Launch 3D Slicer, open the Extensions Manager, search for NNUNet and install it.

  3. Restart 3D Slicer

    Close and reopen Slicer so the extension is loaded.

  4. Download the DentoFac extension

    Save this package somewhere you can find it again — do not unpack it.

    Download DentoFac extension

    DentoFac-git2616ec3-2026-08-09.tar.gz · 368 KB · Windows and Linux

  5. Install it from file

    In the Extensions Manager, choose Install from file and select the .tar.gz package you just downloaded.

  6. Restart 3D Slicer again

    Reopen Slicer so the DentoFac module appears in the modules list.

  7. Install the NNUNet requirements

    Go to DentoFac → DentoFac Hub and click Install NNUNet Requirements.

    Depending on your internet speed this takes anywhere from 10 to 60 minutes, or longer. Progress is printed in the Python console — open it from View → Python Console if you want to watch it.

    Slicer may look frozen while this runs — that is normal. Do not close it or force-quit; simply leave it alone until the installation finishes.

Please finish the setup at home. Conference Wi-Fi will not be fast enough for the model download on the day of the session.
